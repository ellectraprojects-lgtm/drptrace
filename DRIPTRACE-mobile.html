ALPHA: remaining fluid is estimated from calibrated scale weight. BETA: remaining fluid is estimated from counted drops. Both use the same GPIO23 LDR for live DPM. If HX711 is missing or uncalibrated, ALPHA shows a fault rather than fake readings.
